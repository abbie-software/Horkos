The demo story: Amara asks her AI Buyer Agent to buy a small coding job: a Python function that converts a CSV file into JSON. Horkos checks the payment against her rules, holds the money, and runs automatic tests on the seller’s code, paying the seller only if the tests pass and refunding Amara if they fail. Along the way, a seller earns trust and a higher spending limit, and then a Red Team attack tries to redirect the payment and gets blocked.
